[개념 정리] 4일차 — 여러 변동이 겹친 발음

한 단어에서 음운 변동이 여러 번 일어날 때는 대체로 ‘음절의 끝소리 규칙·자음군 단순화 → (ㄴ 첨가) → 비음화·유음화’ 순서로 따져 보면 된다. ㅎ이 있으면 먼저 거센소리되기나 ㅎ 탈락을 확인한다.

① 끝소리·자음군 단순화 → 비음화

앞마당 → [압마당] → [암마당] / 값만 → [갑만] → [감만] / 읽는 → [익는] → [잉는] / 흙냄새 → [흑냄새] → [흥냄새] / 맏며느리 → [만며느리]

② 끝소리 → ㄴ 첨가 → 비음화

꽃잎 → [꼳입] → [꼳닙] → [꼰닙] / 홑이불 → [혿이불] → [혿니불] → [혼니불] / 밭일 → [받일] → [받닐] → [반닐]. ‘꼬닙’, ‘호디불’처럼 쓰면 오답이다.

③ ㅎ이 끼어 있을 때

거센소리되기: 꽃향기 → [꼳향기] → [꼬턍기], 깨끗하다 → [깨끋하다] → [깨끄타다], 국화[구콰]. 거센소리되기 → 구개음화: 닫히다 → [다티다] → [다치다].

ㅎ 탈락 → 유음화: 끓는 → [끌는] → [끌른], 닳는[달른]. ㅎ 뒤의 ㄴ: 놓는 → [녿는] → [논는], 쌓네[싼네].

④ 거센소리되기와 된소리되기가 함께

법학과 → [버팍과] → [버팍꽈]. ‘법학’에서 ㅂ과 ㅎ이 [ㅍ]으로 합쳐지고, ‘학과’에서 받침 ㄱ 뒤의 ㄱ이 [ㄲ]이 된다. [버팍과](된소리되기 누락), [법팍꽈](ㅂ이 남음)는 모두 오답이다. 같은 방식으로 복잡하고[복짜파고], 읍내를[음내를]처럼 어절 전체를 끝까지 읽어야 한다.

<보기 1>의 문장을 표준 발음으로 읽을 때 유의할 점을 정리한 것이 <보기 2>이다. ①~④에 들어갈 적절한 말을 쓰시오.
